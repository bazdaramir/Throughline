# THROUGHLINE

*Engineering memory for AI-assisted development.* Your agent forgets everything. This is where what you decided stays decided.

> [!tip] The only rule
> You are never asked to write documentation. Capture happens as a by-product of work. **Your one ritual is to clear [[#⚠ Needs your attention]] once a week.** One ritual is sustainable. Five are not.

---

## ▸ Getting started  (delete this section when done)

- [ ] Run `/throughline:init` in a repo
- [ ] Run `/throughline:backfill --since 90d`
- [ ] Promote or drop the drafts in **Needs your attention** below
- [ ] Start a Claude Code session and read the brief
- [ ] Capture one thing today: `/throughline:decide` or `/throughline:gotcha`

*The `/throughline:*` commands come from the Claude Code plugin — see the repository README for the
two-line install. Without it this vault still works by hand: open `90 Templates/` and write a note
yourself. That is the whole system; the plugin only removes the typing.*

## ▸ Quick actions

| Do this | How |
|---|---|
| Record a decision | `/throughline:decide` — or `90 Templates/Decision.md` |
| Record a landmine | `/throughline:gotcha` — or `90 Templates/Gotcha.md` |
| Map a subsystem | `/throughline:map` — or `90 Templates/Component.md` |
| Ask why something is the way it is | `/throughline:why <topic>` |
| Load context before changing code | `/throughline:brief <area>` |
| Run the hygiene audit | `/throughline:audit` |
